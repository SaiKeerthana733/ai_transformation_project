# AI Transformation Project

## 🎯 Overview
This project is an AI-driven analysis tool that helps organizations identify industry challenges and propose transformation strategies.  
It integrates **FastAPI** for backend processing, **Streamlit** for frontend visualization, and **SQLite** for storing past analyses.

## ⚙️ Features
- Upload documents (PDF, DOCX, TXT) for analysis
- Real-time industry insights via Tavily API
- Categorized outputs:
  - Business Situation
  - External Change
  - Strategic Issues
  - Opportunities
  - Priorities
  - Initiatives
  - Outcomes
- Database storage for historical comparisons

## 🚀 Tech Stack
- Python
- FastAPI
- Streamlit
- SQLite
- Tavily API
